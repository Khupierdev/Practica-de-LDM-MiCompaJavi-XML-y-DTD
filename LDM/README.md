# LDM - Ejercicios XML

Este proyecto contiene una colección de ejercicios prácticos relacionados con XML (eXtensible Markup Language) y DTD (Document Type Definition). Los archivos están diseñados para aprender y practicar conceptos básicos y avanzados de XML, incluyendo validación, estructura de documentos y corrección de errores.
